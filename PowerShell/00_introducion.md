# 🧠 ¿Qué es PowerShell?

PowerShell es:

- Un **shell de línea de comandos** (como CMD o Terminal).
- Un **lenguaje de scripting** para automatizar tareas.

Originalmente creado para Windows, ahora es **multiplataforma**:  
✅ Funciona en **Windows**, **Linux** y **macOS**.

---

## 🖥️ ¿Por qué usar una consola?

**Ventajas frente a interfaces gráficas:**

- ⚡ Más rápido para tareas repetitivas.
- 🤖 Ideal para automatización (como en DevOps).
- ☁️ Permite interactuar con la nube y otros recursos.
- 📁 Los comandos se pueden guardar en archivos `.ps1`, lo que facilita:

  - 🔍 **Auditorías** (seguimiento de cambios).
  - 🔁 **Repetibilidad** (ejecutar lo mismo varias veces).
  - 🗂️ **Control de versiones** (con Git, por ejemplo).

---

## 🔧 Características clave

### 🔄 Similitudes con otros shells

- 📚 Sistema de ayuda integrado (`Get-Help`)
- 🔗 Canalización (`|`) para encadenar comandos
- 🧭 Alias: comandos cortos como `ls`, `cls`, etc.

### 🚀 Diferencias con otros shells

- 🧱 Trabaja con **objetos**, no solo texto → facilita filtrado y análisis.
- 🧩 Usa **cmdlets** (comandos especiales como `Get-Process`, `Set-Item`)
- 🧬 Tiene varios tipos de comandos:
  - Ejecutables
  - Funciones
  - Scripts
  - Alias

## 🛠️ Instalación

### 🪟 En Windows 8 o superior

Ya viene instalado como **Windows PowerShell**.

### 🐧 En Linux/macOS o versiones antiguas de Windows

Debes instalarlo manualmente.  
📄 Consulta la [documentación oficial](https://learn.microsoft.com/es-es/powershell/scripting/install/installing-powershell?view=powershell-7.5).
