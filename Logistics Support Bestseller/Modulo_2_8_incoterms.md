# MÓDULO 2 — INCOTERMS  
## Parte 8: Cómo negociar Incoterms con proveedores

Negociar Incoterms no es solo elegir una regla:  
es **gestionar poder, costes, riesgos y control operativo**.

Aquí aprenderás estrategias reales aplicadas a moda, retail y mercancías peligrosas.

---

# 1. Principios clave para negociar Incoterms

## ✔ Principio 1: El Incoterm debe beneficiar a ambas partes
Un Incoterm desequilibrado genera:
- retrasos  
- disputas  
- costes ocultos  
- mala relación comercial  

## ✔ Principio 2: El Incoterm debe adaptarse al tipo de mercancía
- Contenedores → FCA, CPT, CIP  
- DG → FCA o CIP  
- Aéreo → FCA o CIP  
- Terrestre UE → DAP  

## ✔ Principio 3: El Incoterm debe reflejar quién controla mejor la logística
- Si tú tienes mejores tarifas → FCA  
- Si el proveedor tiene mejores tarifas → CPT/CIP  
- Si quieres simplicidad → DAP  

---

# 2. Qué Incoterms aceptar y cuáles rechazar

## 👍 Incoterms recomendados
- **FCA** → control, seguridad, exportación clara  
- **CIP** → seguro amplio, proveedor paga transporte  
- **DAP** → simplicidad, entrega en tu almacén  
- **CPT** → proveedor paga transporte, tú controlas importación  

## ⚠ Incoterms a evitar (en la mayoría de casos)
- **EXW** → problemas con exportación en origen  
- **FOB** → incorrecto para contenedores  
- **CFR/CIF** → riesgo pasa en origen, pero proveedor paga flete  
- **DDP** → riesgos fiscales y legales para el vendedor  

---

# 3. Estrategias de negociación según el tipo de proveedor

---

## A) Proveedores asiáticos (China, Bangladesh, India)

### Problema habitual:
Proponen **FOB** por costumbre.

### Estrategia:
1. Explicar que para contenedores es incorrecto.  
2. Proponer **FCA** en la terminal.  
3. Argumentar:
   - “FCA nos permite controlar el flete y mejorar tiempos.”
   - “FOB genera disputas porque no controlas la carga a bordo.”

### Resultado esperado:
Proveedor acepta FCA sin problema.

---

## B) Proveedores europeos (Portugal, Italia, Turquía)

### Problema habitual:
Quieren simplificar la operación.

### Estrategia:
1. Proponer **DAP** a tu almacén.  
2. Argumentar:
   - “Es más eficiente para ambos.”  
   - “Nos permite planificar mejor la recepción.”  

### Resultado esperado:
Proveedor acepta DAP porque es simple y directo.

---

## C) Proveedores de mercancía peligrosa (perfumes, aerosoles)

### Problema habitual:
No tienen transportistas DG fiables.

### Estrategia:
1. Proponer **FCA** para controlar el transportista.  
2. Si el proveedor tiene buena logística DG → **CIP**.  

### Resultado esperado:
Mayor seguridad y cumplimiento normativo.

---

# 4. Frases de negociación listas para usar

## Para cambiar FOB → FCA
- “Para contenedores, la ICC recomienda FCA. FOB puede generar disputas en la carga.”  
- “Con FCA evitamos problemas en la terminal y mejoramos tiempos.”

## Para proponer CIP
- “Si ustedes pueden asumir el transporte y seguro, CIP nos da estabilidad de costes.”  
- “CIP nos permite trabajar con un seguro ICC-A, más adecuado para esta mercancía.”

## Para proponer DAP
- “DAP nos permite planificar mejor la recepción y reducir tiempos de tránsito.”  
- “Si ustedes gestionan el transporte, nosotros nos encargamos de la importación.”

## Para rechazar DDP
- “DDP implica riesgos fiscales y aduaneros para ustedes. DAP es más seguro para ambos.”

---

# 5. Cómo usar los Incoterms para mejorar costes

## ✔ Estrategia 1: Comparar tarifas
Si tus tarifas son mejores → FCA  
Si las del proveedor son mejores → CPT/CIP

## ✔ Estrategia 2: Negociar volumen
“Si consolidamos X contenedores al mes, podemos pasar a FCA/CIP.”

## ✔ Estrategia 3: Aprovechar hubs logísticos
- Turquía → excelente para DAP  
- China → excelente para FCA  
- UE → excelente para DAP/DPU
